Design a complete, production-quality web application UI/UX for:

# SENTINELAI

### AI-Powered Multi-Modal Digital Threat Detection & Digital Authenticity Analysis Platform

SentinelAI is a professional cybersecurity and digital forensics platform that allows users to analyze digital content for deepfakes, manipulated documents, phishing URLs, scam/social-engineering content, and potentially malicious files.

The interface must feel like a serious enterprise cybersecurity product used by security analysts, digital forensic investigators, organizations, and researchers.

DO NOT design this as a futuristic cyberpunk website.

DO NOT use neon green/red hacker aesthetics, excessive gradients, glowing effects, matrix backgrounds, skulls, terminal-style decoration, or gaming UI.

The visual language should be:

* Modern
* Professional
* Minimal
* Technical
* Trustworthy
* Enterprise-grade
* Clean
* Data-driven
* Security-focused
* Highly usable
* Suitable for an academic/research project and future commercial deployment

Use a refined light-first interface with optional dark mode.

===============================================================================

1. DESIGN SYSTEM
   ===============================================================================

Create a consistent design system across the entire application.

COLOR DIRECTION:

Primary:

* Deep navy / dark blue
* Professional blue
* Neutral slate

Supporting:

* White
* Very light gray
* Slate gray
* Subtle blue-gray surfaces

Semantic colors:

* Green = Low / Safe
* Yellow/Amber = Medium / Warning
* Orange = High
* Red = Critical / Malicious

Use semantic colors sparingly.

Avoid making the entire interface colorful.

TYPOGRAPHY:

Use a modern professional sans-serif such as:

* Inter
* Geist
* IBM Plex Sans

Use clear hierarchy:

* Large page titles
* Medium section headings
* Small labels
* Highly readable body text
* Monospace typography only for hashes, URLs, IP addresses, technical indicators, and code-like data

COMPONENT STYLE:

* Rounded but not excessively rounded cards
* 8–12px border radius
* Thin subtle borders
* Minimal shadows
* Strong spacing system
* Clear information hierarchy
* Compact but readable data tables
* Professional icons
* Consistent button styles
* Accessible contrast

The application should feel similar in quality to modern enterprise products such as professional security operations platforms, cloud security dashboards, and high-end SaaS products.
